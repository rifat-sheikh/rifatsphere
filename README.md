# RifatSphere — personal website

A responsive, dark, minimal personal website for Rifat, aspiring agritech entrepreneur.

## What's included
- `index.html` — complete website (HTML, CSS, and JavaScript in one file)
- `assets/` — reserved for your portrait or future images
- `.nojekyll` — helps GitHub Pages serve the site without Jekyll processing

## Preview locally
Open `index.html` in any modern browser.

## Publish free with GitHub Pages
1. Sign in to GitHub and create a **public** repository named exactly `rifatsphere.github.io` under the account whose username is `rifatsphere`.
2. Upload `index.html`, `.nojekyll`, and the `assets` folder (if present) to the repository root.
3. Open **Settings → Pages**. If needed, choose **Deploy from a branch**, select `main` and `/ (root)`, then Save.
4. Wait a few minutes and visit `https://rifatsphere.github.io`.

The URL only works if the GitHub username is actually `rifatsphere` and the repository name is exactly `rifatsphere.github.io`. If the username is different or unavailable, choose another free Pages URL.

## Add your portrait later
Create an `assets` folder, add your photo as `rifat-portrait.jpg`, then edit `index.html` where desired. The current hero uses a lightweight CSS illustration, so the site works without a photo.

## Customization
Search in `index.html` for your email, YouTube URL, text, and section labels to update them. This is a static site; no paid hosting, database, or framework is required.

## Privacy
Your email address is displayed publicly on the website. Use a dedicated public contact email if you prefer not to expose your personal address.
